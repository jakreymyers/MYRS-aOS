# Skills

Skills live in `.claude/skills/` — each has a `SKILL.md` with full usage docs.

Invoke with `/skill-name` or the Skill tool.

| Skill | When to use |
|-------|-------------|
| `google` | Gmail, Calendar, Drive, Sheets, Docs, Slides, Contacts via `gog` CLI |
| `memory` | **Proactive.** Query before responding about people, projects, companies, decisions, or org context. Search and entity lookup for grounded answers |
| `open-prose` | Run `.prose` files, `prose` commands, or orchestrate multi-agent workflows |
| `frontend-design` | Build production-grade frontend interfaces with high design quality |
| `canvas-design` | Create visual art/designs as `.png` or `.pdf` |
| `design-improvement` | Iterative screenshot-based critique loop to refine app UI aesthetics |
| `image-to-svg` | Convert raster images to production-ready SVG via Potrace/VTracer with preprocessing, tuning, and verification |
| `webapp-testing` | Test and interact with local web apps via Playwright |
